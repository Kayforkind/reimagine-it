# Security

This repository is **markdown instructions** for coding agents. There are no bundled scripts that call networks or run as installers.

- Review any skill you install before the agent follows it.
- Do not paste API keys into chat or commit `.env`.
- The skill tells the agent to **ask before** billed image/video/model APIs.
- Optional `local.md` (gitignored) is for a host’s private chairs. Do not publish it.
