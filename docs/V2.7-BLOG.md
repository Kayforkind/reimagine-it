# reimagine-it v2.7.0 — the honesty layer becomes a product surface

*Paste-ready dev.to article. Cover image: `docs/og.png`. Tags: `ai`, `webdev`, `css`, `opensource`.*

---

Two weeks ago v2.6.0 fixed a quiet lie: some generator layouts only showed the
first 4–10 facts of your source and dropped the rest. The repo's own fidelity
floor test caught it — worst case, 33% of a page's numbers never made it into
the redesign.

v2.7.0 turns that honesty into product. Three things shipped:

## 1. `extract` — see exactly what the engine reads

Before redesigning anything, you can now ask the engine what it sees:

```bash
npx reimagine-it extract -i page.html -o signals.json
```

You get JSON: anchors, proper nouns, dates, numbers, emails, links, the
derived palette, and the hex colors that were actually in your source. Every
extracted fact exists in the source — this is property-tested now, including
against hostile and malformed HTML (no crashes, no invented facts, deterministic).

It's the difference between "trust me" and "here is the inventory."

## 2. Proof is CI-enforced

Three new guards run on every push:

- **Reproduction guard** — every committed example must regenerate
  byte-identically from the committed engine. Stale proof cannot ship.
- **Stills guard** — every screenshot must exist at canonical dimensions and
  match its deployed copy.
- **Weekly stress** — 250 seeds × 15 tokens × 9 sources against the 80%
  fidelity floor.

Plus: the npm publish step now ships with signed provenance, and the
playground's pasted HTML runs in a sandboxed iframe.

## 3. `mcp` — eight design tools over stdio

```bash
npx reimagine-it mcp
```

Point any MCP host at it (Claude Desktop, Cursor, anything that speaks the
protocol). Tools include `reimagine`, `design_auto`, `design_variations`,
`design_lock`, `extract_content`, and `audit_html`.

## Also in v2.7.0

- Three new focused sub-skills (`generate`, `variations`, `extract`) completing
  the SkillsBench-backed split — focused skills measurably outperform one
  monolithic SKILL.md.
- The community lane is open: copy `examples/community/TEMPLATE/`, paste your
  real page, pass the validator, get merged with credit.
- A dataset builder (`scripts/build-dataset.js`) that emits
  `{source_html, signals, output_html}` tuples from the committed, verified
  examples — 21 pairs today, for anyone training design-capable models.
- `docs/llms.txt` for agents: the whole product in one machine-readable page.

## Try it

```bash
npx reimagine-it --auto -i page.html -o redesign.html
npx reimagine-it audit redesign.html   # 19 deterministic checks
```

Or paste HTML into the [playground](https://kayforkind.github.io/reimagine-it/#playground)
— no install, runs entirely in your browser.
