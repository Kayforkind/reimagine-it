# Proof case — Maison Vesper (photoshoot campaign)

- **Author:** Kayforkind (maintainer proof, same bar as community submissions)
- **License of the source copy:** original copy written for this study, owned by the repo
- **Kind:** proof case — a photoshoot/campaign page, the job the `lookbook`
  direction exists for and none of the nine journeys covers

## What proves

Auto should read the campaign vocabulary (campaign, looks, collection,
photography, editorial facts) and land `lookbook` — an editorial spread with
numbered looks — rather than a data poster or a generic landing page. The
palette must come from the source hex values: noir `#1A1614`, vermillion
`#C1442E`, bone `#EFE6D8`.

## The bar

1. `source.html` is real copy — every fact findable in the file after redesign.
2. Auto reports fidelity ≥ 80%.
3. `node ../../scripts/validate-submission.js examples/community/maison-vesper`
   passes.
4. The redesign opens offline.
