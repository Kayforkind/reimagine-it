# Code of Conduct

## Pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Standards

**Do**

- Be respectful and stay on the work: packs, gold, bugs, docs
- Give and take critique on the *source* and the *output*, not the person
- Credit other people’s work
- Assume good intent; ask before escalating

**Do not**

- Insult, harass, or personal attacks
- Sexualized language or imagery, or sexual attention
- Doxxing, publishing private contact, or posting `local.md` / secrets
- Trolling, or flooding issues and PRs with generated noise
- Publishing others’ private information without permission

## Scope

This Code applies in the GitHub repo, issues, PRs, discussions, and any official project space (including when someone is representing the project).

## Enforcement

Report unacceptable behavior privately:

- [Open a private security advisory](https://github.com/Kayforkind/reimagine-it/security/advisories/new) if the report includes sensitive details
- Or mention [@Kayforkind](https://github.com/Kayforkind) on a GitHub issue and ask for a private follow-up

Do not put home addresses, phone numbers, or passwords in public issues.

Project maintainers will review reports, take action they believe is appropriate (warning, edit, lock, or ban), and will not share reporter identity beyond what is needed to act.
