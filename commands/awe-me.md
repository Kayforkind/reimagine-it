# /awe-me — invent a leap from context

Load and follow the installed **awe-me** skill (`SKILL.md`). Also `references/notes.md`, `references/forms.md`, `examples.md`.

Copy this file to `~/.cursor/commands/awe-me.md` if you want the slash in Cursor.

## Invocation

| Command | Behavior |
|---------|----------|
| `/awe-me` | Sniff → adjacent possible → four notes → hero artifact + stretch. **No interview.** |
| `/awe-me interview` | Optional talk. Agent decides questions (one at a time + recommended answer), then builds |
| `/awe-me code` / `cli` / `protocol` / `demo` / `prose` / `product` / `architecture` / `experiment` | Force form family |
| `/awe-me svg` / `3js` / `infographic` / `canvas` / `html` | Force visual |
| `/awe-me interview cli` | Combine |
| `/awe-me --notes` | Include the four notes in the report |
| `/awe-me --plan-only` | Lock + notes + form; do not write files |
| `/awe-me --full` | Plus-pass after the hero |
| `/awe-me <brief>` | Context + brief |

`/inspire-me` is the **same chair**, elevation/Tuesday-door default.

## Hard contract

1. Read the skill before acting
2. Interview **only** if they chose `interview`
3. Default: infer and build. Awe is **not** graphics-only
4. Ship an artifact (unless `--plan-only`)
5. Name a stretch they did not know was possible
6. No wow-factor, no paid APIs without asking, no commit unless asked
7. Report `AWE: shipped | partial | blocked`
